プライバシーポリシー

制定日: 2026年7月25日 / 改定日: 2026年9月23日

世界新奈 (以下「当方」といいます) は、スマートフォンアプリ「ミトレル (Meetrail)」(以下「本アプリ」といいます) および本ウェブサイトにおける利用者の情報の取扱いについて、以下のとおり定めます。

1. 取得する情報

1-1. アカウントに関する情報

ログイン方法 取得する情報
メールアドレス メールアドレス
Apple でサインイン Apple が発行する利用者識別子、およびメールアドレス (Apple の設定でメールアドレスを非公開にした場合は、Apple が発行する転送用アドレスのみを取得します)
Google でサインイン Google が発行する利用者識別子、およびメールアドレス
ゲスト利用 (匿名ログイン) 本アプリが自動発行する識別子のみ (メールアドレス等は取得しません)

氏名、住所、電話番号、生年月日、支払い情報は取得しません。

1-2. 利用者が本アプリに入力した情報

  • ミーグリの申込・当選・落選・キャンセルの記録、参加の記録、当選の支払い状況
  • 受付ごとの申込計画 (どの枠に何枚投げるか)、および申込みプランの申込済みの記録
  • レポの本文、会話 (やりとり) の記録、その日の髪型・服装のメモ、非公開メモ
  • メモ (話したいこと) と、そのタグ・一日のしおりへの割り当て
  • レター (公式メッセージアプリに送るための文面) と、その送付日
  • メモ・レポ・レターに付けたタイトルと URL
  • やりとりの記録や共有画像に表示する、自分の表示名・アイコンと、メンバーの呼び名・アイコン (アイコンが絵文字の場合は絵文字、写真の場合は端末内の保存場所を示す文字列のみ)
  • アプリを使い始める前のミーグリについて、手で入力した枚数
  • forTUNE から取り込んだ申込・当選の内容 (枠・メンバー・申込数・当選数)、 および同じ申込を二重に取り込まないための申込の識別番号
  • カレンダー連携の購読 URL に使う識別子 (第3項を参照)
  • 推しメンの設定、単価の設定、その他アプリ内の設定

写真・動画そのものは当方のサーバーへ送信しません (1-3 を参照)。

1-3. 端末内にのみ保存される情報

次の情報は利用者の端末内にのみ保存され、当方のサーバーへは送信されません。

  • ログイン状態を保つための認証情報
  • メモ・レポ・レター・やりとりに添付した写真・動画、およびアイコンに使う写真
  • 書いている途中のメモ・レポ・レターの下書き
  • シリアル入力補助で読み込んだ応募券の画像、読み取ったシリアル、作業の進み具合。 読み取りは端末内で行います。登録済みのシリアルは、同じものを再び入力しないよう、 元の値に戻せない形 (ハッシュ値) でのみ保存します
  • forTUNE のページから受け取った内容のうち、取り込みを確定する前のもの
  • 通知の設定、お知らせの既読状態、その他の表示状態

1-4. 取得しない情報

本アプリは以下を取得しません。

  • 位置情報
  • 連絡先、カレンダーの予定、通話履歴
  • マイクの音声
  • 広告識別子 (IDFA / AAID)
  • 行動履歴・利用状況の解析データ
  • forTUNE のページに表示される氏名・住所・電話番号・メールアドレス、およびログイン情報

1-5. 端末の機能の利用

  • 写真ライブラリ — 利用者が選んだ写真・動画だけを読み込みます (添付、アイコン、応募券の読み取り)。また、共有用の画像を保存するために書き込みを行います。
  • カメラ — 応募券を撮影して読み取るときだけ使います。
  • 通知 — ミーグリや受付・支払い期限のお知らせは、端末内で予約する通知です。 通知のために端末の識別子 (プッシュトークン) をサーバーへ送ることはありません。
  • Safari の拡張機能 (iOS) — 利用者が操作したときだけ動きます。 forTUNE の取り込みでは、対象ページから申込・チケットの内容を読み取ります。 シリアル入力補助では、公式の応募ページの空欄にシリアルを入力します (応募の確定ボタンは押しません)。

本アプリには広告 SDK および行動分析ツールを組み込んでいません。 ただし不具合の調査のため、エラー記録ツール (Sentry) を利用しています (第4項を参照)。

2. 利用目的

  • 本アプリの機能を提供するため (記録の保存・表示・同期、通知、カレンダー連携)
  • 本アプリの利用者全体の記録から、枠ごとの混み具合の目安を算出するため (第3項を参照)
  • 不具合の調査および対応のため
  • お問い合わせへの対応のため
  • 利用規約に違反する行為への対応のため

3. 匿名集計と、他の利用者への表示

本アプリには、どの枠が混み合っているかの目安を表示する機能があります。この機能は、 本アプリの利用者が入力した当選等の記録を集計して算出しています。 したがって、利用者が入力した当選の記録は、集計を通じて他の利用者の画面に反映されます。

集計にあたっては次の取扱いをします。

  • 個人を特定できる情報は含めません。 誰がどの枠に何枚当選したかが、他の利用者に開示されることはありません。
  • 集計に用いるのは申込・当選に関する数値のみです。 レポ、メモ、レター、非公開メモの本文は集計にも表示にも用いません。
  • 集計結果は目安であり、実際の販売状況・当落を保証するものではありません。 集計の方法は、精度向上のため予告なく変更することがあります。
  • アカウントを削除すると、その利用者の記録は集計の対象から外れます。

レポ・メモ・レター等の本文が、当方によって他の利用者に公開されることはありません。 利用者自身がレポ・しおり・計画表・完売表・話した時間を画像として書き出し、SNS 等へ投稿する機能はありますが、これは利用者の操作によるものです。

カレンダー連携について

カレンダー連携を使うと、当選した枠の予定 (日時・部・メンバー名・枚数・会場) を カレンダーアプリから購読できる URL を発行します。 この URL を知っている人は誰でも、その予定を読むことができます。 URL を他の人に教えないでください。計画・メモ・金額は含みません。 URL はマイページ → カレンダー連携 から再発行 (古い URL は無効になります) または解除できます。

4. 第三者サービスの利用

本アプリは、機能の提供のために以下の外部サービスを利用しています。

サービス 用途 渡る情報
Supabase データベースおよび認証基盤 第1項に記載した情報 (サーバーの所在地: 日本・東京リージョン)
Expo (EAS Update) アプリの更新の配信 更新の取得に伴う通信情報 (IP アドレス、アプリのバージョン等)
Sentry 不具合 (エラー・クラッシュ) の記録と調査 エラーの内容、アプリのバージョン、端末・OS の情報、および利用者を識別する ID。 メールアドレス・表示名・IP アドレスは送信しません
Apple (iTunes Search API) シングルのジャケット画像の表示、およびアプリの最新バージョンの確認 作品やアプリを指定する番号と、通信に伴う情報 (IP アドレス等)。 利用者の記録は送信しません
Apple Apple でサインイン Apple 側の認証手続きに必要な情報
Google Google でサインイン Google 側の認証手続きに必要な情報

上記以外の第三者に対して、利用者の情報を提供・販売することはありません。ただし、法令に基づく 開示請求を受けた場合を除きます。

5. 保存期間

取得した情報は、利用者がアカウントを削除するまで保存します。アカウントを削除すると、 当該利用者の記録・計画・レポ・メモ・レター・設定はサーバーから削除されます。 端末内にのみ保存している写真・下書き等は、アプリを削除すると端末から消去されます。 削除の手順は データの削除について をご覧ください。

なお、バックアップに含まれるデータは、バックアップの保存期間の経過をもって消去されます。

6. 安全管理措置

  • 通信はすべて暗号化 (HTTPS) して行います。
  • データベースには行レベルのアクセス制御を設定し、利用者本人以外が他人の記録を参照できない 構成としています。
  • ログイン情報は端末のセキュアな領域に保存します。

7. Cookie 等について

本ウェブサイトは Cookie を使用せず、アクセス解析ツールも設置していません。 ただし、本ウェブサイトは GitHub Pages 上で公開されており、 サーバー提供元において接続記録が保存される場合があります。

本ウェブサイトでは、文字表示のために Google Fonts を読み込んでいます。 この際、閲覧者の IP アドレス等が Google に送信される場合があります。

8. 開示・訂正・削除の請求

利用者は、自身の情報の開示・訂正・利用停止・削除を請求できます。 記録の訂正および削除はアプリ内でいつでも行えますが、それ以外のご請求は 第10項のお問い合わせ先までご連絡ください。ご本人であることを確認のうえ、 合理的な期間内に対応します。

9. 未成年の利用について

未成年の方が本アプリを利用する場合は、保護者の同意を得たうえでご利用ください。
